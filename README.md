# 猫の词课 · 小春的英语教室

四级、六级分开的 Galgame 风格英语学习与猫娘养成网站。纯静态 HTML / CSS / JavaScript，无需构建或后端。

- CET-4、CET-6 独立学习记录、单词搜索和分页。
- 四级、六级独立听力训练，含句意理解、关键词听辨、语速切换、原文对照和听力错题重练。
- 阅读、汉译英和计时写作三个专项训练室，四级、六级分别出题并记录完成量。
- 词义选择、音标、浏览器朗读、例句和错题复习。
- 猫娘老师微笑、开心、遗憾、害羞四种表情，支持鼠标点击和手机触摸。
- 小春养成包含 0–100 好感、每日课后互动、学习联动、五阶段课堂台词和高低好感专属表情。好感 70、80、90、95 可依次选择限定衣装，100 时全部解锁；选择永久保存。
- 基础衣装包括森系学院、草莓绒绒和晴海假日；特别校服及纪念帆布包使用专属兑换码领取，且不占用好感奖励名额；限定衣装包括夜猫黑丝、绯夜猫铃、白昼恋歌、紫罗兰韵、月夜女仆、黑曜蕾影、薄荷蕾丝、糖果缎带和酒红夜曲。新加入的四套衣装均包含常态、答对、答错、害羞、高好感和低好感六种独立状态。紫罗兰韵采用参考款灰紫短旗袍与披肩，白昼恋歌使用普通白丝长手套。
- 衣橱兑换入口支持开发者码 `666666`；开启后右上角常驻显示开发者模式，并开放全部衣装，不改动好感度。
- 草莓绒绒、晴海假日和夜猫黑丝在养成界面使用独立的大腿以上近景立绘与专属姿势，不影响课堂答题表情和立绘鉴赏。
- 手机、平板和电脑适配。学习记录保存在当前浏览器 localStorage，不上传服务器。

## 使用

打开 `index.html`，或使用任意静态服务器托管此目录。GitHub Pages 从 main 分支根目录发布。无需安装依赖。

键盘 1–4 选择答案；听力页可用空格重播、回车进入下一题。鼠标或触摸点击老师可触发害羞表情。

## 词库

来自 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary) 的 `full_line_jsonl/sentence/正序/四级.jsonl` 与 `六级.jsonl`，获取日期 2026-09-07。

原始四级 7,508 条、六级 5,651 条，按英文词头去重后四级 4,544 词、六级 3,992 词。重复词头采用最后一条记录；保留其音标、释义、短语与例句。两级使用来源原始分类，六级书不自动包含所有四级基础词。

这是社区整理的学习词库，并非官方大纲完整性认证。词义题和听力题由词库例句生成，不是考试真题或历年考试录音。第三方词库内容权利归原作者及来源方，本项目不另行授予第三方内容授权。
